# Privacy Policy — Cartoon Factory

*Last updated: 17 November 2026*

## Summary

Cartoon Factory collects no personal data from anyone. It is a tool run by one
person, on that person's own computer, to upload videos to that same person's
own YouTube channel. There are no other users, no accounts to create, no
analytics and no tracking.

## What we collect

Nothing. Specifically:

* No personal data of any kind is collected, stored or transmitted to us.
* There is no sign-up, no account and no user base: the only person who
  authorises the application is its owner.
* There are no analytics, no advertising and no third-party tracking.

## Google user data

The application asks its owner — and only its owner — for permission to use
these Google API scopes:

* `https://www.googleapis.com/auth/youtube.upload` — to upload a video file to
  the owner's own YouTube channel.
* `https://www.googleapis.com/auth/youtube` — to set the title, description,
  tags and thumbnail of those same videos, and to read back the public view
  counts of the owner's own videos in order to decide what to make next.

These permissions are used for nothing else. The data they give access to is
never sold, never shared with third parties, and never used for advertising or
for training machine-learning models.

The authorisation token Google issues is stored only on the owner's own
computer and is never transmitted anywhere else. The owner can revoke it at any
time from the [Google account permissions page](https://myaccount.google.com/permissions).

Cartoon Factory's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Children

The application is not directed at children and collects no data from anyone,
children included.
